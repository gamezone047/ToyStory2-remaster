FULL CO-OP CAMPAIGN TEST - 2026.11.7.13

One run through the whole campaign with two players. Goal: find every mismatch in one pass.

BEFORE YOU START
- Both PCs: update to the same version with the launcher (the lobby rejects different versions).
- Host: Multiplayer > Host. Player 2: Join the host's IP. Start game.
- Delete old logs first so the run is clean:
  * <game folder>\CoopBridge.log (on both PCs)
  * %LOCALAPPDATA%\ToyStory2\Diagnostics\host-launcher.log / client-launcher.log
- Console: press ` (backtick). "coop" shows the sync status line, "follow" takes you to the other
  player's level, "lvl1".."lvl15" moves both players, "unstuck" frees your Buzz.

WHEN SOMETHING LOOKS WRONG
- Immediately open the console and type "coop" (this also writes a full status line to the log).
- Note: level, room/place, what you did, who acted (host or player 2), what each PC showed.
- Keep playing; one note per problem is enough.

TEST PATTERN FOR EVERY MECHANISM
- A: the host does it while player 2 watches from nearby.
- B: player 2 does it while the host watches from nearby.
- C (where possible): one player does it while the other is far away / in another room, then comes back.
- Check: same position and state on both PCs, it counts once, nobody gets stuck or launched by the
  other player's action, riding is smooth for the rider.

10 floor-switch puzzle (three floor switches; press them from both PCs, the indicators move the

12 Boss: start as each player; hits once; defeat.
13 two balances, five moving platforms (ride as each player), rescued friend.
14 Lamp puzzle: same lamps/moves on both; presses from each PC count once; run out of moves once;

15 Final boss: three bosses; hit each from both PCs; a boss only goes down once for both;
   final cutscene and completion.

SESSION CHECKS (once during the run)
- Pause on one PC: both pause; resume.
- One player dies and the level restarts for them: progress (doors, switches, bosses) must come
  back, nothing rewinds for the other player.
- Disconnect player 2's network for ~10 s, reconnect: the game keeps running, the lobby says
  "Reconnecting...", sync resumes without restarting.
- Use "follow" after the players end up on different levels.
